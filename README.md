### Часть 1. Практическая работа №1-1: «Страница о стране»
1. Откройте ваш локальный репозиторий в **VS Code**.
2. Создайте файл `index.html` и пустой файл `style.css`.
3. Задайте базовую структуру HTML5. В теге `<title>` укажите название страны строго по вашему варианту:
   * **В-1** Египет; **В-2** Турция; **В-3** Болгария; **В-4** Хайнань; **В-5** Греция; **В-6** Албания; **В-7** Черногория; **В-8** Хорватия; **В-9** Испания; **В-10** Марокко; **В-11** Тунис; **В-12** Италия; **В-13** Португалия; **В-14** Кипр; **В-15** Эмираты; **В-16** Куба; **В-17** Доминикана.

#### Требования к контенту страницы:
* Заголовок `<h1>` с названием страны.
* Минимум 3 логических раздела (используйте семантический тег `<section>`, использование универсальных `<div>` **запрещено**).
* Нумерованный список `<ol>` (например, *«Топ-5 достопримечательностей»*).
* Маркированный список `<ul>` (например, *«Что взять с собой»*).
* Минимум 3 работающие внешние гиперссылки (Википедия, туристические порталы).
* Ссылка `mailto:` на вашу рабочую почту в футере страницы.

### Часть 2. Практическая работа №1-2: «Мои курсы»
Вы создаете персональную семантическую страницу студента вечернего отделения.

#### Разметка структуры страницы (Строго обязательно):
* `<header>`: содержит заголовок `<h1>Мои курсы (группа ППОИС-...)` и приветствие в теге `<p>`.
* `<nav>`: содержит неупорядоченный список (`<ul>`) с якорными ссылками внутри страницы: `#courses`, `#resources`, `#notes`.
* `<main>`: объединяет основное содержимое страницы.
* `<section id="courses">`: заголовок `<h2>`, внутри — нумерованный список (`<ol>`) текущих предметов и ФИО преподавателей.
* `<section id="resources">`: заголовок `<h2>`, внутри — маркированный список (`<ul>`) со ссылками на учебные платформы (Coursera, Stepik, MDN). Внешние ссылки обязаны иметь атрибут `target="_blank"`.
* `<section id="notes">`: заголовок `<h2>`, внутри — список описаний (`<dl>`, `<dt>`, `<dd>`) с краткими конспектами по Теме 1 и Теме 2.
* `<aside>`: краткая карточка автора (Ваши Фамилия, Имя и группа).
* `<footer>`: ссылка-заглушка «На главную» (`href="#"`), контактный `mailto:ваш-email` и знак копирайта `© 2026`.

#### 🛡️ ANTI-AI барьер для уровня JUNIOR:
* Запрещается отправлять весь код одним монолитным коммитом (ИИ генерирует все за один раз).
* Вы обязаны делать итеративную разработку в **VS Code** (сделали разметку — коммит, наполнили списки — коммит). Всего должно быть **не менее 4 коммитов**.
* Каждый коммит должен содержать префикс зоны ответственности. Текстовый лог команды `git log --oneline` из терминала VS Code нужно обязательно скопировать в окно описания PR.
  * *Пример:* `structure: добавил каркас и семантические секции`
  * *Пример:* `content: заполнил списки курсов и дефиниций`

#### 💡 Простыми словами для новичков: что это значит?

1. **Что такое «префикс зоны ответственности»?**
   Представьте, что коммит — это коробка с вещами, которую вы отправляете на склад. Префикс — это крупная наклейка на коробке, чтобы сразу было понятно, что именно внутри, без её открытия. Вместо непонятных названий вроде *"сделал"*, *"исправил"* или *"лаба"*, вы должны сначала написать **главное слово (префикс)**, поставить двоеточие, а затем указать, что изменилось.
   * ❌ **Как неправильно:** `добавил шапку`, `исправил ссылки`, `финал`.
   *  **Как правильно:** 
     * `structure: добавил каркас и семантические секции` (если работали с тегами структуры).
     * `content: заполнил списки курсов и дефиниций` (если наполняли блоки текстом).
     * `links: настроил якорное меню и ссылки mailto` (если работали с тегами ссылок).

2. **Как достать «текстовый лог команды git log --oneline»?**
   Когда вы полностью закончите работу и сделаете все коммиты, вам нужно показать преподавателю историю ваших шагов:
   * В нижней части окна **VS Code** откройте вкладку **Terminal** (Терминал). Если его нет, нажмите сверху `Terminal` -> `New Terminal`.
   * Введите в строку терминала команду: `git log --oneline` и нажмите клавишу Enter.
   * На экране появится красивый короткий список ваших коммитов (история вашей работы).
   * Выделите эти строчки мышкой, скопируйте их (`Ctrl+C` или `Cmd+C`) и вставьте в текстовое поле вашего Pull Request на GitHub в отведенное для этого место.
